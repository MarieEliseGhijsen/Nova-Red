# Nova-Red
A WIP 2.5D shooter written in C using [raylib](https://www.raylib.com/), inspired by classic games like Wolfenstein 3D

Level data is stored using YAML files

## Tech

- **C**
- **raylib**
- **YAML**

## Status

Work in progress - currently focused on building the core systems for rendering, player movement, level handling, and pathfinding before moving on to enemies and combat
